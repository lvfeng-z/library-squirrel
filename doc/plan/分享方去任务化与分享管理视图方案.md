**自曝风险**：

- 徽标数据从 el-badge 直连迁菜单注册表的注册时序（mount 后注册）

## 一、背景与动机

用户实操二期交付后反馈：成功分享的 share-host 任务**常驻 Processing**——语义错位：任务面板心智是「有始有终的工作」，隧道维持是长驻服务；「重试」语义怪异（=重新注册新链接）；重启后残留指向已死会话的任务行。

**用户裁决（2026-08-27）**：分享方分享**不走任务逻辑**（当初《分享功能总体方案.md》决策10/16「接入任务」本意指**接收方**将拉取作为任务）；单开一张分享表存储自己的分享；分享有重型管理 UI 需求，**单开菜单和视图**承载。

**决策修订**（《分享功能总体方案.md》）：
- 决策10/16 的 share-host 部分撤销 → 分享方会话不经任务模块；share-receive（收件拉取）任务建模**不变**（决策12 断点续传语义完全归属收件侧，成立）
- 决策10 的「不要求自动重建」同步推翻 → 有效期内启动自动复原（bind 重绑，见 B 节）
- 「关 App 链接即失效」语义弱化为「关 App 链接临时失效，有效期内重开应用自动恢复」——发布弹窗成功态与落地页兜底文案随改（阶段2）

## 二、方案

### A. share-host 任务化退役（backend）

1. `Publish` 直跑：Service 内 goroutine 驱动 HostSession 主体（收集→注册→隧道维持），进度/complete 仍走 share-events（现链路，零前端改动）；取消（弹窗「取消」）经 Service 的 cancel 通道（会话本地终止）。goroutine 以 recover 包装监督：panic 时推 complete 失败事件收尾弹窗（发布弹窗已锁中途关闭——`close-on-click-modal/escape/show-close` 均 false，「取消」按钮是运行中唯一中断路径，无中途关闭歧义）
2. 退役清单：`TaskTypeHost` 常量、`HostExecution`（task_execution.go 只留 ReceiveExecution）、`app.go:914/1174-1177` 装配回退（策略表只留 share-receive）、`CreateBuiltinTask` 的 host 调用点、`backend/share/share_test.go:916`（TestHostExecutionLifecycle）随退役改写为直跑形态
3. 存量 share-host 任务行：启动一次性迁移**物理删除**（task 表 task_type='share-host' 的行）
4. SDK `taskType` 字段**保留**（share-receive 在用）
5. 发布运行的取消语义：弹窗「取消」→ Service 直接终止会话（不经任务控制面）
6. **启动复原入口**：Service 提供 `RestoreAll`（应用启动稳定后调用，对 share_record 全部 active 行执行 B 节复原流程；逐条独立 goroutine，互不阻塞）；app.go 装配接线

### B. 分享表（持久化）

新实体 `ShareRecord`（建议表名 `share_record`，与内存 session 概念区分）：

| 字段 | 类型 | 说明 |
|---|---|---|
| id/create_time/update_time | BaseEntity | |
| share_id | string 唯一 | 业务键（现 share-N） |
| token | string | 中继会话 token |
| title | string | 落地页标题 |
| work_ids / work_set_ids | JSON | 分享对象 |
| relay_address | string | 中继地址 |
| key | string | E2E 密钥 Base64（待决策4：明文入表） |
| password_protected | bool | 是否有密码（不存密码明文/摘要——摘要属运行时载荷） |
| expire_seconds / expires_at | int64 | 有效期配置与到期时刻 |
| file_count / total_bytes | int64 | 规划统计（MissingFiles 一并记） |
| state | string | active / revoked / expired / failed（失败附原因；无「随进程失效」态——启动自动复原吸收） |
| revoked_at | int64 | 撤销时刻（0=未撤销） |

- 写入点：注册成功（首次 online）落 active 行；撤销→revoked；到期→expired（会话终态事件驱动）；复原失败（作品已删/中继 not_found）→failed 并记原因
- **启动自动复原（裁决6）**：对全部 active 行逐条执行「重新收集（work_ids）→ 规划 → `bind` 重绑（原 token，PROTOCOL.md L86-87）」——链接不变、剩余有效期由中继侧会话管理（bind 无需重传 expiresAt）；收集失败/中继回 not_found→落 failed；中继不可达→会话重连循环（reconnecting，不落表终态）
- 运行态（connecting/online/reconnecting）**不入表**——仍内存 session + state 事件实时推；视图按 share_id 关联两源显示
- `file_count`/`total_bytes` 旁记 MissingFiles（源文件缺失条数，发布时规划统计产出）

### C. ShareView 视图 + 菜单

1. 新视图 `frontend/src/views/ShareManage.vue`（路由 share-manage）：进行中会话区（运行态徽标/复制链接/撤销）+ 历史分享 DataTable（标题/作品数/大小/中继/有效期/状态/时间/操作=复制链接·失效禁用 + **删除记录**）
2. 「接收分享」入口迁入视图（按钮触发既有 ShareReceiveDialog——弹窗本体保留）
3. 菜单：`useBuiltinMenus.ts` 注册（图标+名称「分享」），徽标=菜单注册表新建迁移（el-badge 直连 getter 现状退役）
4. ShareManageDialog 退役（功能并入视图）；MainView 顶栏分享管理图标**移除**
5. SharePublishDialog 发布弹窗**保留**（轻交互：配置+进度+成功链接，链路零改动）
