- 决策4（非阻塞）：`url`/`marketplace` 预注册状态键——推荐注册（两行别名，防未来值落进来时无样式兜底）。
- 决策5（非阻塞）：PluginDialog 标题残留修复 + 补来源/信任只读展示——推荐做（一行修复 + 两行展示）。

**已裁决（2026-08-25）：** 对抗式审查通过（零证伪，4 处文档级修正已落：声明5 锚点改 427、声明3 补 DataTable.vue:237、免责文案去色相字样、风险4 补纪律出处）。决策1-5 全部按推荐项定案：颜色二分+渠道文案 / 新增信任列 / 加免责提示（不含色相字样）/ 预注册 url 与 marketplace / 修复 PluginDialog 并补展示。

**自曝风险：**
- 风险1：StatusTag 对未注册 key 无兜底样式（CSS 变量缺失时无边框无底色、文案回退为 key 原文）——全枚举注册后不触发，但后端未来新增来源枚举值时需同步登记，属登记义务。
- 风险2：信任 undefined 语义翻转（`非false即已信任`→`非true即未信任`）改变远古 NULL 数据的展示——保守方向（显示未信任引导用户确认），操作幂等无害。
- 风险3：来源列加 StatusTag + 新增信任列后表格总宽增加（操作列已 280px），小屏可能出横向滚动——实机验证项。
- 风险4：纯前端变更的最小验证命令即 `yarn build:dev`（前端无按文件粒度的构建），与「禁全量构建作为常规阶段验证」纪律（`doc/plan/_CONVENTIONS.md:53`）存在张力——本方案以「前端已是构建最小粒度」为由使用之，阶段内以输出结尾行为断言。

## 背景

开放插件生态已定（主程序 GPL-3.0、SDK+四插件 MIT、允许第三方付费插件），主仓库 README 已加「第三方插件声明」免责节（`README.md:69-73`）。本任务是它在 UI 上的对应物：让用户在插件管理页一眼分清**官方捆绑插件**与**第三方安装插件**，售后与付费权益找谁一目了然。

后端数据链路完整（声明1），纯前端接线任务。

## 来源列方案（决策1推荐项）

**颜色承担「官方/第三方」二分，文案保留渠道细分**：

| Source 枚举值 | 状态 key | 文案 | tone | 说明 |
|---|---|---|---|---|
| bundled | `plugin-bundled`（已登记） | 官方 | done 绿 | 官方捆绑，随主程序分发 |
| local | `plugin-local`（已登记） | 本地 | idle 灰 | 本地包安装（第三方主渠道） |
| url | `plugin-url`（新增） | 网络 | idle 灰 | 预留值，无生产者 |
| marketplace | `plugin-marketplace`（新增） | 市场 | idle 灰 | 预留值，无生产者 |

绿=官方、灰=第三方——一眼二分；文案保留渠道信息（来源枚举的本义），且与筛选下拉选项一一对应。三渠道共用 idle 灰是刻意的：**色相只表达「是否官方」一个维度**，渠道细分交给文案，避免三色分散暗示渠道间有官方性差异。

各主题（forest/ocean/sakura）无需新增覆盖——`plugin-*` 别名引用 done/idle/warn tone，tone 值由各主题自行覆盖后自动跟随（tokens.css 现状即此结构，theme-*.css 中无 plugin 条目，grep 确认）。

## 信任列方案（决策2推荐项）

新增「信任」列（StatusTag，宽度 ~90）：

- `trusted === true` → `plugin-trusted`（新增登记：label 已信任，done 绿 tone）
- 其他（false/undefined/null）→ `plugin-unverified`（已登记：warn 橙）

bundled 恒为 true 统一显示「已信任」，不做官方特判——展示与运行门控事实一致，避免特例分支。

同时将状态抽屉「信任状态」判断从 `trusted === false` 翻转为 `trusted === true`（风险2）。

## 免责提示（决策3推荐项）

在插件列表上方（检查更新告知区块同层）加一行 muted 小字：

> 来源标记区分官方捆绑插件与第三方插件；第三方插件由其作者独立维护，其交易（含付费）与权益问题请找插件作者。

文案与 README 免责节对齐（`README.md:71-73`）；不写具体色相（官方标记颜色随主题 tone 变化，文案绑定「绿色」会与主题调色脱节）。仅当列表存在非 bundled 插件时显示，官方全绿时省略（避免纯官方库下常驻噪音）。
