# 标题栏主题色控制方案

> 状态：评审中
> 日期：2026-06-23
> 范围：后端新增 Windows DWM 调用模块 + handler；前端主题切换时同步标题栏颜色
> 平台：仅 Windows 11 (22000+) 完整生效；Windows 10 有限兜底；macOS/Linux 无操作

## 一、背景与目标

用户希望 Windows 原生窗口的**标题栏**（标题文字 + 最小化/最大化/关闭按钮区）颜色跟随应用主题切换。

**当前条件（已具备）**：
- Windows 使用原生标题栏（`main.go` 未设 `Frameless`）。
- 主窗口 HWND 已获取并保存于 `App.mainHWND`（`main.go:144-146` 赋值，`app.go:98` 定义，`app.go:445` 已传给插件 HostDeps）。

**目标**：主题切换时，标题栏背景与文字色同步更新，与内容区视觉融合。

## 二、设计决策（已确认）

1. **标题栏背景跟随 `--app-bg-page`**（页面背景色）：标题栏紧邻内容区顶部，用 page 色可实现无缝衔接，低调不抢眼。这是用户选定的方案。
2. **标题栏文字跟随 `--app-text-primary`**（`#303133`）：page 色为浅色，深色文字保证对比度。
3. **Windows 11 完整支持**任意背景/文字色；**Windows 10 仅兜底**为亮色标题栏（`DWMWA_USE_IMMERSIVE_DARK_MODE = false`），不支持任意颜色。
4. **macOS/Linux 无操作**：Mac 已用 `MacTitleBarHiddenInset`（隐藏原生标题栏）；Linux 标题栏由桌面环境控制。非 Windows 平台 handler 空实现。

### 各主题标题栏配色

标题栏背景 = 该主题的 `--app-bg-page` 值；文字统一 `#303133`。

| 主题 | 标题栏背景（page） | 标题栏文字 |
|---|---|---|
| 默认蓝（default-light） | `#eaeef4` | `#303133` |
| 森林绿（forest-light） | `#e8efe5` | `#303133` |
| 海洋蓝（ocean-light） | `#e2f0f2` | `#303133` |
| 樱花粉（sakura-light） | `#f5e6ea` | `#303133` |

## 三、技术路径

通过 Windows DWM API（`dwmapi.dll` 的 `DwmSetWindowAttribute`）：

| 属性常量 | 值 | 作用 | 支持平台 |
|---|---|---|---|
| `DWMWA_USE_IMMERSIVE_DARK_MODE` | 20 | 暗色标题栏开关（BOOL） | Win10 19041+ / Win11 |
| `DWMWA_BORDER_COLOR` | 34 | 窗口边框色 | Win11 22000+ |
| `DWMWA_CAPTION_COLOR` | 35 | 标题栏背景色 | Win11 22000+ |
| `DWMWA_TEXT_COLOR` | 36 | 标题文字色 | Win11 22000+ |

- 颜色格式：`0x00BBGGRR`（BGR 字节序，alpha 固定 00）。
- 调用签名：`DwmSetWindowAttribute(hwnd, attribute, *value, sizeof(value))`。

## 四、详细设计

### 4.1 后端：新建 `backend/window/` 模块

**`titlebar_windows.go`**（`//go:build windows`）：

```go
//go:build windows

package window

import (
	"syscall"
	"unsafe"
)

var (
	dwmapi                   = syscall.NewLazyDLL("dwmapi.dll")
	procDwmSetWindowAttribute = dwmapi.NewProc("DwmSetWindowAttribute")
)

const (
	dwmwaUseImmersiveDarkMode = 20
	dwmwaBorderColor          = 34
	dwmwaCaptionColor         = 35
	dwmwaTextColor            = 36
)

// setTitleColor 设置标题栏背景与文字色（hex 格式 #RRGGBB）
func setTitleColor(hwnd uintptr, bgHex, textHex string) error {
	bg, err := hexToBGR(bgHex)
	if err != nil {
		return err
	}
	text, err := hexToBGR(textHex)
	if err != nil {
		return err
	}
	if err := setAttr(hwnd, dwmwaCaptionColor, bg); err != nil {
		return err
	}
	if err := setAttr(hwnd, dwmwaTextColor, text); err != nil {
		return err
	}
	// 浅色标题栏：关闭暗色模式
	_ = setAttrBool(hwnd, dwmwaUseImmersiveDarkMode, false)
	return nil
}

func setAttr(hwnd uintptr, attr uint32, color uint32) error {
	r1, _, e1 := procDwmSetWindowAttribute.Call(
		hwnd, uintptr(attr),
		uintptr(unsafe.Pointer(&color)),
		unsafe.Sizeof(color),
	)
	if r1 != 0 {
		return e1
	}
	return nil
}

// hexToBGR 将 #RRGGBB 转为 0x00BBGGRR
func hexToBGR(hex string) (uint32, error) { /* 解析 #RRGGBB → R,G,B → 0x00BBGGRR */ }
```

**`titlebar_other.go`**（`//go:build !windows`）：

```go
//go:build !windows

package window

	return nil // 非 Windows 平台无操作

```

**`service.go`** + **`handler.go`**：

```go
type Service struct {
	hwnd uintptr
}

func NewService(hwnd uintptr) *Service { return &Service{hwnd: hwnd} }

// SetTitleBarColor 设置主窗口标题栏颜色
func (s *Service) SetTitleBarColor(bg, text string) error {
	if s.hwnd == 0 {
		return errors.New("主窗口句柄未就绪")
	}
	return setTitleColor(s.hwnd, bg, text)
}
```

```go
type Handler struct{ svc *Service }

func (h *Handler) SetTitleBarColor(bg, text string) *model.ApiResponse[any] {
	return model.HandleVoid(h.svc.SetTitleBarColor(bg, text))
}
```

**注册**（`app.go`）：在 `mainHWND` 赋值后构造 `window.NewService(app.mainHWND)`，注册 `WindowHandler` 到 Services；并在 `main.go` 的 Services 列表加入 `application.NewService(app.WindowHandler)`。

### 4.2 前端集成

**`themes.ts`** 扩展 `ThemeMeta`：

```ts
export interface ThemeMeta {
  id: ThemeId
  name: string
  swatch: { primary: string; bg: string; surface: string }
  /** 标题栏配色（Windows 原生标题栏，随主题同步） */
  titleBar: { bg: string; text: string }
}
```

每个主题填入：`titleBar: { bg: '<page色>', text: '#303133' }`。

**`apis/http/wrappers/window.ts`**（新）：封装 `WindowHandler.SetTitleBarColor(bg, text)`。

**`UseThemeStore.ts`**：在 `load()` 与 `setTheme()` 应用主题后，调用 `windowApi.setTitleBarColor(currentTheme.titleBar.bg, currentTheme.titleBar.text)`。

### 4.3 时序

1. `main.go` 窗口创建 → `app.mainHWND` 赋值（已存在）。
2. `windowService` 构造时注入 `mainHWND`。
3. 前端 `app.mount` → `useThemeStore().load()` 读取持久化主题 → 应用 `data-theme` + 调用 `setTitleBarColor`。
4. 用户切换主题 → `setTheme()` → 同步标题栏。

> HWND 就绪先于前端 mount（`mainHWND` 在 `LoadPlugins` 前赋值，`Run` 后才 mount 前端），时序安全。

## 五、限制与边界

1. **Windows 10**：`DWMWA_CAPTION_COLOR/TEXT_COLOR` 调用会失败（返回非 0），标题栏保持系统默认。兜底：调用 `DWMWA_USE_IMMERSIVE_DARK_MODE = false` 确保亮色标题栏（与浅色主题协调）。可在后端检测版本，Win10 仅执行兜底。
2. **颜色精度**：DWM 不支持 alpha，标题栏为纯色（page 色本就是不透明 hex，无影响）。
3. **多窗口**：当前仅主窗口（`mainHWND`）。对话框等独立窗口（`OpenWindow`）的标题栏不在本期范围。
4. **主题恢复**：Windows 系统主题/强调色改变不影响本设置（DWM 属性持久作用于该窗口，直到重新设置或窗口销毁）。

## 六、实施阶段

- **阶段 1（后端）**：新建 `backend/window/`（windows 实现 + other 占位 + service + handler），`app.go`/`main.go` 注册并注入 HWND；`wails3 generate bindings -ts`。
- **阶段 2（前端）**：`themes.ts` 加 `titleBar`；新建 `window.ts` wrapper；`UseThemeStore` 在 `load`/`setTheme` 后调用。
- **阶段 3（验证）**：`task dev` 切换 4 套主题，确认标题栏背景跟随 page 色、文字清晰；确认 Win10 兜底（若有 Win10 环境）。

## 七、可选增强（本期不做）

- 对话框/子窗口标题栏同步。
