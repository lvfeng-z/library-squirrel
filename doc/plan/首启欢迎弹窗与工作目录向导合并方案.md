## 需求概述

首启引导的第一印象从「居中警示气泡」改为「欢迎弹窗」：模态但无暗色遮罩、欢迎语气、退出仅「开始使用」与「查看新手向导」两个按钮（后者醒目）。工作目录警示从首屏移入设置页——点「查看新手向导」后启动的合并版工作目录向导（删居中警告步，警示文案融入设置页区块说明步）。看过一次欢迎弹窗即不再弹；其余既有链路（任务向导自动接续、常驻横幅兜底、存量迁移零打扰）不变。

## 需求详情

### 功能列表

1. **欢迎弹窗组件**（`frontend/src/components/tour/WelcomeDialog.vue` 新建）：
   - el-dialog，`modal=true` + `modal-class` 自定义类将遮罩背景设为透明——保留点击拦截（模态）但无暗色视觉遮罩；
   - `show-close=false`、`close-on-click-modal=false`、`close-on-press-escape=false`——退出方式仅两按钮；
   - 内容：标题「欢迎使用 LibrarySquirrel」+ 一句功能简介（如「个人资源库——从远程站点下载资源到本地，用标签组织你的收藏」，文案实施时可微调）+ 无警示语；
   - 按钮组：「查看新手向导」（`type="primary"`、尺寸加大，醒目）与「开始使用」（默认样式）；
   - 样式全走 `--app-*` 主题令牌（THEME_TOKEN_USAGE 规则）。
2. **workdir-setup 重定义**（`definitions.ts`）：删居中警告步，改为两步（决策2/3）：
   - 第一步：`target: { route: 'settings', targetKey: 'settings.workdirSection' }`，标题「工作目录」，描述 = 区块作用说明 + 原强度警示：「这里设置资源库的根目录，本软件管理的所有资源都会被保存到这个目录下。若不配置工作目录，资源下载、备份与文件服务均不可用」；
   - 第二步：`target: { route: 'settings', targetKey: 'settings.workdirInput' }`，标题「设置目录」，描述保留现有加长文案（`definitions.ts:23`）。
3. **Settings.vue 注册新区块目标**：工作目录设置区块（标题 + 输入行，`Settings.vue:424` 附近）挂 ref 并 `registerTourTarget('settings.workdirSection', ref)`（风险2：必要时加包裹 div）。
4. **首启触发链切换**（`UseWorkdirStatusStore.ts`）：
   - `refresh()` 拉取判据从 `completed['workdir-setup']` 改为 `completed['welcome-shown']`；`applyPulled` 未配置分支：`welcome-shown` 未标 && 本会话未弹过 → 置欢迎弹窗可见（不再 `start('workdir-setup')`）；已标或本会话弹过 → 升横幅；
   - state 新增 `welcomeVisible`；会话防抖键随语义改名（`wizardAttempted` → `welcomeAttempted`）；
   - store 新增欢迎关闭入口（供弹窗两按钮编排调用）：置 `welcomeVisible=false`、`markCompleted('welcome-shown')` 持久化；若由「开始使用」关闭且未配置 → 升横幅。
5. **弹窗按钮编排**（WelcomeDialog 内）：
   - 「查看新手向导」：关弹窗 + 标记 + `tourCenter.start('workdir-setup')`——跳设置页由向导引擎按第一步 `target.route` 自动完成（声明7 既有机制），无需手动路由跳转；
   - 「开始使用」：关弹窗 + 标记 + 未配置升横幅。
6. **迁移扩展**（`UseTourCenterStore.ts` `migrateLegacyFirstTime`）：存量 `first-time===true` 迁移时同时标 `welcome-shown=true`——存量用户看过旧引导即视为看过欢迎，零打扰；与既有迁移同批持久化。
7. **挂载**：MainLayout 模板挂 `<WelcomeDialog />`；接续编排（声明8）与 `onTourEnded` 横幅兜底不动。

### 用户场景

- **全新用户首启**：主页欢迎弹窗（无暗色遮罩、欢迎语气）→ 点「查看新手向导」→ 自动跳设置页 → 第一步区块说明（含原强度警示）→ 第二步高亮输入框 → 填写保存 → 完成 → 任务创建向导自动接续（既有链）。
- **全新用户点「开始使用」**：弹窗关闭、标记已看过、未配置升常驻横幅；下次启动不弹欢迎；向导中心随时可手动查看向导。
- **存量用户**（first-time 已迁移）：启动时迁移补标 welcome-shown，不弹欢迎、横幅语义照旧，零打扰。
- **向导中心**：workdir-setup 条目呈新版两步；task-creation 与 local-tag-intro 不变；欢迎弹窗不进向导中心（无重置入口，看过即终结）。

### 数据模型

- 无数据库实体变更。`settings.tour.completed`（JSON 用户设置内向导完成标记映射）新增键 `welcome-shown`——**非向导标记借住该表**（声明6 已核验不泄漏进向导中心列表）；持久化走既有 `markCompleted` 链（新增键落盘不受已知 D1 缺陷「map 键删除不落盘」影响——D1 只影响删除，不影响新增）。

### API 设计

无新增/变更 IPC。既有复用：`settingsGetSettings`（refresh 判据拉取）、`settingsSaveSettings`（markCompleted 持久化链）。

### 边界条件

- **已配置用户**：`applyPulled` 首分支（workdir 非空）直接收横幅返回，永不弹欢迎。
- **看过欢迎但未配置**（点「开始使用」）：下次启动 `welcome-shown` 已标 → 不弹欢迎、升横幅。
- **运行期未配置事件**（`onUnconfiguredEvent`）：只升横幅，不弹欢迎——欢迎仅首启分流触发。
- **弹窗期间交互锁定**：modal=true 遮罩（透明）拦截背后点击；esc 与遮罩点击均不关闭（仅两按钮）。
- **D1 缺陷交互**：first-time 磁盘键因 D1 不被删除 → 每次启动重迁 → welcome-shown 反复重标 true，幂等无害；若 D1 修复（旧键真正删除）后，迁移已完成过一轮、新键已落盘，同样无害。
- **向导中心手动重看 workdir-setup**：不弹欢迎（欢迎不挂向导中心），走完 + 已配置 + task-creation 未看过仍触发接续（既有闸门不变）。

## 技术方案

### 涉及模块

| 文件 | 改动 |
| --- | --- |
| `frontend/src/components/tour/WelcomeDialog.vue` | 新建：欢迎弹窗（透明遮罩模态、两按钮编排） |
| `frontend/src/tour/definitions.ts` | workdir-setup 重定义（删居中警告步，两步均落设置页） |
| `frontend/src/views/Settings.vue` | 工作目录区块挂 ref + 注册 `settings.workdirSection` |
| `frontend/src/store/UseWorkdirStatusStore.ts` | 判据切 `welcome-shown`；`welcomeVisible` 状态与欢迎关闭入口；防抖键改名 |
| `frontend/src/store/UseTourCenterStore.ts` | `migrateLegacyFirstTime` 扩展补标 `welcome-shown` |
| `frontend/src/MainLayout.vue` | 挂载 `<WelcomeDialog />` |

### 技术要点

- **模态无暗色遮罩**：el-dialog `modal=true`（保留遮罩层点击拦截 = 模态）+ `modal-class="welcome-overlay"` 自定义类把该遮罩背景改为 `transparent`（风险1 备选：全局 CSS 按 `.welcome-overlay` 类圈定覆盖背景色）。禁止直接 `modal=false`——那是无遮罩但非模态，背后 UI 仍可点击。
- **欢迎标记持久化**：复用 `markCompleted('welcome-shown')`（声明4 既有链），弹窗显示后由按钮关闭动作触发标记——不在弹窗显示瞬间标记（防中途崩溃/强关导致标记丢失后永不弹的边缘语义；以「用户主动关闭」为看过凭证）。
- **按钮编排时序**：「查看新手向导」先关弹窗（`welcomeVisible=false`）再 `start('workdir-setup')`——向导引擎接管路由跳转（声明7），MainLayout 向导结束 watch 的接续链对本次结束照常生效。
- **警示文案位置**：欢迎弹窗零警示；原强度警示全文移入 workdir-setup 第一步描述（决策3），与区块作用说明同气泡。
- **横幅升格收口**：「开始使用」关闭且未配置的横幅升格逻辑放 workdirStatus store 的欢迎关闭入口内（与 `onTourEnded` 同型：判 `!configured && !bannerVisible`），组件不直接改 `bannerVisible`。
